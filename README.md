# Gram Legal Sahayak — Frontend

React + TypeScript + Vite + Tailwind CSS frontend.

## Run
1. `npm install`
2. Copy `.env.example` to `.env`
3. Set `VITE_API_URL=http://localhost:4000/api` (or your deployed API)
4. `npm run dev`

The app keeps the existing routes and UI flow, with responsive fixes, session refresh, persistent profile images, working document search, AI loading feedback, and admin dashboard updates.
